# สงครามอิทธิพล

เกมกระดานมาเฟีย 20×20 ขยายอิทธิพล เล่นกับบอทหรือสลับเครื่องกับเพื่อนได้ในเบราว์เซอร์

เกมทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว (รวมภาพแมพไว้แล้ว) ไม่ต้องติดตั้งอะไร

## วิธีขึ้น GitHub Pages (ประมาณ 3 นาที)

1. เข้า github.com แล้วล็อกอิน กดปุ่ม **New** เพื่อสร้าง repository
   - ตั้งชื่อ เช่น `mafia-turf`
   - เลือก **Public**
   - กด **Create repository**
2. ในหน้า repo ที่ว่างอยู่ กดลิงก์ **uploading an existing file**
   - ลากไฟล์ `index.html` และ `README.md` ใส่
   - กด **Commit changes**
3. ไปที่ **Settings** > **Pages**
   - Source เลือก **Deploy from a branch**
   - Branch เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอ 1 ถึง 2 นาที เกมจะเปิดได้ที่
   `https://<ชื่อผู้ใช้ GitHub ของคุณ>.github.io/mafia-turf/`

## หมายเหตุ

- ฟอนต์โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ตตอนเปิดเกม
- เวอร์ชันนี้ยังเป็นโหมดเครื่องเดียว (สู้บอท หรือผลัดกันเล่น) ระบบเล่นออนไลน์จะเพิ่มในขั้นต่อไป
